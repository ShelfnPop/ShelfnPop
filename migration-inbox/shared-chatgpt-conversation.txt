Thought for 17s

Yes — you are in the right place as long as this is the main body Column that contains all four dashboard cards.

Correct setup

The Supabase query should be on the parent widget that contains the dashboard values:

DashboardPage
└── Column  ← query goes here
    ├── Welcome text
    ├── Subtitle
    ├── Row: Total Pops / Total Value
    ├── Row: Total Paid / Gain/Loss
    ├── Scan Pop button
    └── My Collection button

So this part in your screenshot is good:

Supabase Query
user_collection_summary_view
Filter: user_id = [User ID]
What to check next

Select each large value text inside the cards and bind it to the query result from that Column:

Card	Bind value to
Total Pops	user_collection_summary_view Row → total_quantity
Total Value	user_collection_summary_view Row → total_collection_value
Total Paid	user_collection_summary_view Row → total_purchase_cost
Gain/Loss	user_collection_summary_view Row → total_gain_loss

Do not bind from App State or static text.

Important

The builder preview may still show:

0
$0.00

because those are your fallback/default values.

The real test is:

Test Mode → DashboardPage

If the user is logged in, the dashboard should show something like:

Total Pops: 5
Total Value: $14.99
Total Paid: $7.99
Gain/Loss: $7.00
One thing I’d clean up

You probably don’t need a ListView inside the Dashboard unless you want the whole page scrollable. A plain Column is fine for now.

If you keep the ListView, make sure the summary query is still on a parent that contains all the cards. The query being on the main Column is the right idea.

SQL
select
  upc,
  pop_name,
  character,
  franchise,
  number,
  variant,
  pop_style,
  exclusivity,
  api_source,
  raw_title,
  clean_title
from public.pop_catalog
where franchise is null
   or franchise in (
     'Funko',
     'Funko LLC',
     'Funko, LLC',
     'POP',
     'Pop! Vinyl',
     'DreamBone',
     'Grappiq'
   )
   or pop_name ~* '(vinyl|bobblehead|figures|000[[:space:]]+[0-9]+|\([[:space:]]*\)|chance of chase|[[:space:]]\(other\))'
order by pop_name;
