# Funko Collection App

Local workspace for continuing the Funko collection app design and prototype.

## Open the prototype

Open `index.html` in a browser. The app runs as a static page and saves collection edits in browser local storage.

## Migration from ChatGPT project

The original ChatGPT project link redirects to sign-in from this environment, so the previous project files could not be imported automatically.

To migrate the old work, export or copy the relevant ChatGPT project content into `migration-inbox/`, then continue here. Good candidates:

- Product notes or requirements
- Screenshots or mockups
- Data models
- Existing code snippets
- Sample Funko collection data
- Any saved decisions about branding, workflows, or features

## Current prototype scope

- Collection dashboard
- Search and filtering
- Owned, wishlist, and preordered states
- Add-item form
- Local persistence
- Example seed data

## Real App Context

This project is actually a FlutterFlow + Supabase app. See `PROJECT_CONTEXT.md` for the migrated context from the shared ChatGPT conversation.
